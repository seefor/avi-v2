# AVI v2 Episodes

Each episode adds one capability while preserving the controls from every previous layer.

| # | Folder | Core Question |
|---|---|---|
| 01 | `01-tools` | Can an AI safely observe a real network? |
| 02 | `02-evidence` | How do we prove what the agent actually saw? |
| 03 | `03-state` | Can AVI turn pyATS output into usable network state? |
| 04 | `04-structure` | Why must agent output be validated? |
| 05 | `05-scale` | What changes when AVI looks at multiple devices? |
| 06 | `06-context` | What information should AVI actually see? |
| 07 | `07-intent` | How does intended state compare with live state? |
| 08 | `08-rag` | How does AVI use runbooks and operational knowledge? |
| 09 | `09-harness` | What controls belong around the model? |
| 10 | `10-loops` | When should AVI investigate further or stop? |
| 11 | `11-verification` | Does the evidence support AVI's hypothesis? |
| 12 | `12-mcp` | How do AVI's safe tools become reusable? |
| 13 | `13-human-approval` | When does AVI need explicit permission? |
| 14 | `14-change-planning` | What must exist before execution? |
| 15 | `15-controlled-action` | How does AVI safely perform one bounded lab change? |

## Episode Contract

Every episode folder contains a technical README and a `docs/episode-NN-walkthrough.md` teaching guide. The walkthrough is designed to be used while recording the matching YouTube episode.

Every episode must show both a successful path and a failure, rejection, or safety-boundary path.
